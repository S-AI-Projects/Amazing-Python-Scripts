# Last Access

It prints out when was the last the file in folder was accessed.

The `last_access(path)` function prints regular files in the order returned by
`os.listdir`, with each filename followed by its local access time. It does not
sort or modify the directory listing.

## Setup instructions

Just run the script and Enter the path of folder
And press Enter
